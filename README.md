# AI 营销方案工作台

在线体验：[打开工作台首页](https://ai-marketing-workbench-gamma.vercel.app/)。点击“体验工作台”即可使用演示模式；AI 生成需要访客在“模型设置”中填写自己的 DeepSeek Key。

## 在自己的电脑上运行

```bash
git clone https://github.com/yyj0627/ai-marketing-workbench.git
cd ai-marketing-workbench
npm install
npm run dev
```

在运行上述命令的那台电脑上打开 `http://localhost:3000/`，先浏览首页，再点击“体验工作台”进入演示。`localhost` 始终指访问者自己的电脑，这不是公开网站地址。工作台新项目从空白表单开始；已保存的自定义草稿仍会恢复。演示无需账号或 API Key，可体验需求录入、按“前期分析／主体创意／预算分配”组织的十模块方案初稿、逐模块编辑与修改建议、浏览器保存，以及 Word、PPT 导出。演示模式的方案和修改建议由规则生成，页面会明确标记；不会冒充模型输出。

## 使用 DeepSeek

在 `/demo` 点击“模型设置”，选择“使用自己的 Key”，填入 DeepSeek API Key 和模型即可。Key 仅保存在当前浏览器标签页，关闭标签页后需要重新填写；不会写入方案草稿或导出文件。生成时，项目内容与 Key 会通过本站服务端发送到 DeepSeek。公开部署的站点也可以使用这个入口，每个人使用自己的 Key。访客不填 Key 时，默认使用不调用模型的演示模式。

AI 初稿会先规划检索词，调用 DeepSeek Search 搜索并读取相关网页，再让十个方案模块各自使用独立系统提示词、逐模块生成。后面的模块只接收所需的前文和相关检索资料，形成 PEST、消费者、竞品案例、SWOT、主题创意、媒介排期与预算明细。方案撰写阶段的十次模型调用比之前的三次可能更慢，模型用量也可能增加。十条模块提示词及共用的证据和排版规则见 `lib/plan-prompts.ts`。竞品会进行两轮检索，优先写 3—4 个有资料支持的其他品牌案例，逐个说明具体动作、洞察点和适用边界；资料不足时只写可核实的案例。模型只能引用本模块实际收到的检索资料编号，编号只供程序匹配来源；用户看到的是对应章节下可点击的网页链接，Word 和 PPT 中也会保留链接。没有找到可读取网页正文时，AI 生成会报错，而不会假装已有依据。搜索结果和模型解读仍需人工核对，尤其是网页发布时间、案例适用市场和因果关系。没有证据的判断应作为待验证假设；预算金额是规划分配，并非供应商报价。

工作台左侧可上传 PDF、DOCX、PPTX、TXT 或 Markdown 项目资料，最多 4 个，单个不超过 32 MB。服务端只提取文字，不存储原文件；每份提取的文字最多保留前 1 万字。AI 模式生成初稿和修改建议时会参考这些文字，并在引用关键内容时注明文件名。扫描版 PDF、纯图片、Word 旧格式 `.doc` 暂不支持。演示模式不会分析附件。点击“保存修改”后，提取的文字会随方案保存在当前浏览器的本地存储；生成时会发送给 DeepSeek，请勿上传不适合交给模型处理的敏感材料。

联网检索使用同一个 DeepSeek API Key，不需要额外的搜索服务 Key；它会产生搜索接口调用费用。演示模式不调用搜索或模型，也不会生成虚构的网页引用。

如果只在自己的电脑上使用，也可以在项目根目录创建 `.env.local`，填写服务端环境变量：

```text
AI_CHAT_COMPLETIONS_URL=https://api.deepseek.com/chat/completions
AI_MODEL=deepseek-flash
AI_API_KEY=你的 DeepSeek API Key
```

重启 `npm run dev` 后，本机工作台会默认使用这份配置。此时 Key 只由服务端读取，浏览器不会拿到它。若接口出错，页面会显示错误，不会悄悄把规则文本标成 AI 结果。

服务端配置只在开发环境、通过 localhost 或 127.0.0.1 访问时启用；生产环境不会把站点所有者的 Key 开放给访客。公开部署时不要配置 `AI_API_KEY`；如果想使用 AI，请让每位访客在“模型设置”里填写自己的 Key。用户上传的资料不会被系统自动核验。

## 发布为公开网页

本站已部署在 Vercel，并关联这个 GitHub 仓库；推送到 `main` 会触发新部署。GitHub 仓库本身只分享源代码。如果你想部署自己的副本，可在 [Vercel 新建项目](https://vercel.com/new)中导入 `yyj0627/ai-marketing-workbench`，保持框架为 Next.js、根目录为仓库根目录，再点击部署。访客从首页点击“体验工作台”进入 `/demo`，无需账号即可使用演示模式；想要 AI 生成时，在“模型设置”中填写自己的 DeepSeek Key。

公开部署不需要设置任何环境变量，尤其不要配置 `AI_API_KEY`。`/app` 下的账号和项目页是另一条流程，需要额外的 Supabase 配置；公开试用请使用 `/demo`。AI 初稿现在逐一调用十个模块，Vercel 免费 Hobby 计划的函数时长上限为 300 秒；若实际生成超过上限，接口会超时，此时需要缩短生成流程或改用支持更长请求的托管方案。

`.env.local` 已被 Git 忽略，只有不含真实密钥的 `.env.local.example` 会上传。请勿把真实 Key 写入源代码、截图或部署平台的公开环境变量。

原有 `/app` 项目页需要 Supabase 配置，参见 `.env.local.example`。演示工作台与原有项目页目前是两个独立流程；原有项目页还没有连接新方案生成接口。
